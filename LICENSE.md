# Licenza ZeroERP

ZeroERP ha una **doppia licenza**: puoi usarlo sotto la licenza open source
AGPL3, oppure acquistare una licenza commerciale.

## Licenza Open Source (AGPL3)

ZeroERP è rilasciato sotto GNU Affero General Public License v3.0 o successiva
(`AGPL-3.0-or-later`).

Puoi usare, modificare e distribuire ZeroERP gratuitamente a condizione
che il codice derivato rimanga sotto la stessa licenza AGPL3.

A differenza della GPL3, l'AGPL3 vale anche per l'uso **in rete**: se offri
una versione modificata di ZeroERP come servizio (SaaS, hosting, accesso via
browser a utenti esterni), devi mettere a disposizione di quegli utenti il
codice sorgente delle tue modifiche.
