# 📘 Glossario – Problem & Process Analysis

| Sigla     | Significato                                    | Contesto ERP                         | Descrizione sintetica                                                                                                    |
| --------- | ---------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| **BOM**   | Bill of Materials                              | Produzione / Catalogo articoli       | Struttura di composizione degli articoli (distinta base) che definisce materiali e componenti necessari alla produzione. |
| **SKU**   | Stock Keeping Unit                             | Magazzino / Vendite                  | Identificatore univoco di un articolo o variante nel magazzino e nei sistemi di vendita.                                 |
| **UOM**   | Unità di Misura (Unit of Measure)              | Catalogo / Magazzino                 | Standard di misura associato alle quantità degli articoli (es. pezzi, kg, litri).                                        |
| **MRP**   | Material Requirements Planning                 | Produzione / Pianificazione          | Sistema di pianificazione della produzione basato su domanda e disponibilità di materiali.                               |
| **FIFO**  | First In, First Out                            | Magazzino / Logistica                | Metodo di gestione e valorizzazione delle scorte dove gli articoli più vecchi vengono utilizzati o venduti per primi.    |
| **LIFO**  | Last In, First Out                             | Magazzino / Logistica                | Metodo di gestione scorte in cui gli articoli più recenti vengono utilizzati o venduti prima.                            |
| **EAN**   | European Article Number                        | Catalogo / Vendite                   | Codice standard internazionale di identificazione articoli, utilizzato nei codici a barre.                               |
| **GTIN**  | Global Trade Item Number                       | Catalogo / Logistica                 | Identificatore globale dei prodotti utilizzato per il tracciamento commerciale e logistico.                              |
| **ERP**   | Enterprise Resource Planning                   | Sistema gestionale integrato         | Piattaforma integrata per la gestione di processi aziendali (vendite, magazzino, acquisti, contabilità, produzione).     |
| **DDT**   | Documento di Trasporto                         | Logistica / Vendite                  | Documento che accompagna la merce spedita e ne descrive contenuto, quantità e origine.                                   |
| **PDP**   | Punto di Prelievo                              | Utilities / Anagrafiche              | Identificatore del punto di erogazione o misurazione di un servizio (es. energia, gas, acqua).                           |
| **BA**    | Billing Account                                | Fatturazione / Clienti               | Conto di fatturazione associato a un cliente o contratto per la gestione amministrativa.                                 |
| **ETA**   | Estimated Time of Arrival                      | Logistica / Spedizioni               | Stima del tempo di arrivo previsto per una spedizione o consegna.                                                        |
| **ETD**   | Estimated Time of Departure                    | Logistica / Spedizioni               | Stima del tempo di partenza pianificato per una spedizione.                                                              |
| **MRR**   | Material Receiving Report                      | Magazzino / Acquisti                 | Documento di registrazione della ricezione materiali.                                                                    |
| **RMA**   | Return Merchandise Authorization               | Logistica / Post-vendita             | Procedura autorizzativa per la restituzione di merce da parte del cliente.                                               |
| **WIP**   | Work In Progress                               | Produzione / Contabilità industriale | Rappresenta i beni o prodotti in corso di lavorazione non ancora completati.                                             |
| **ABC**   | Activity-Based Costing                         | Contabilità / Controllo di Gestione  | Metodo di attribuzione dei costi basato sulle attività che generano valore.                                              |
| **KPI**   | Key Performance Indicator                      | Analisi / Reporting                  | Indicatore chiave di prestazione utilizzato per misurare l’efficacia dei processi.                                       |
| **SLA**   | Service Level Agreement                        | Servizi / Contrattualistica          | Accordo formale sui livelli di servizio garantiti tra fornitore e cliente.                                               |
| **SOP**   | Standard Operating Procedure                   | Produzione / Qualità                 | Procedura operativa standard che descrive in modo formale le modalità di esecuzione di un processo.                      |
| **B2B**   | Business to Business                           | Vendite / E-commerce                 | Relazione commerciale tra due aziende.                                                                                   |
| **B2C**   | Business to Consumer                           | Vendite / E-commerce                 | Relazione commerciale diretta tra azienda e consumatore finale.                                                          |
| **EDI**   | Electronic Data Interchange                    | Logistica / Scambio dati             | Sistema di scambio elettronico di documenti commerciali tra sistemi ERP.                                                 |
| **API**   | Application Programming Interface              | Integrazione / Sviluppo              | Interfaccia software per l’integrazione di sistemi o applicazioni esterne.                                               |
| **CRON**  | Job Scheduler (Linux)                          | DevOps / Automazioni                 | Sistema di pianificazione automatica di processi periodici in ambiente server.                                           |
| **KISS**  | Keep It Simple, Stupid                         | Principio di design                  | Linea guida per mantenere soluzioni semplici e facilmente manutenibili.                                                  |
| **DRY**   | Don't Repeat Yourself                          | Principio di sviluppo                | Evita duplicazioni di logica e promuove il riuso del codice o delle regole di processo.                                  |
| **RACI**  | Responsible, Accountable, Consulted, Informed  | Project Management                   | Matrice che definisce ruoli e responsabilità nei processi aziendali.                                                     |
