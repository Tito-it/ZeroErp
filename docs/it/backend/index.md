# Backend (Django)

Questa sezione documenta la **logica applicativa Django** di Zero ERP.
La struttura replica quella del DB: per ogni area applicativa ci sono due cartelle:

- `funzioni/` — **auto‑generate** con il source (code/spec)
- `manual/` — **descrizioni concettuali** e note operative

> Nota: la logica di **coerenza dati** e **integrità** resta nel DB; qui documentiamo la **logica di processo** e le API.
> Standard manuale: `it/backend/_templates/manual-standard.md`.
