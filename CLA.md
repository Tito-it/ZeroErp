Perché questo modello resti possibile, ogni contributo deve poter essere

## Come si firma

Alla prima pull request un bot pubblica un commento con il link a questo
accordo. Per firmare basta rispondere nella pull request con la frase indicata
dal bot:

> Ho letto il CLA e lo sottoscrivo / I have read the CLA Document and I hereby sign the CLA

La firma vale per **tutti** i tuoi Contributi futuri, finché la versione del
CLA non cambia. Le firme sono registrate nel repository, sul branch
`cla-firme`, con nome utente GitHub, data e pull request.

Per firmare a nome di un'organizzazione scrivi a <mc.titini@gmail.com>.
